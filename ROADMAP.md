# Roadmap

1. **Phase 0 — Scaffold:** workspace, crate boundaries, skill parser/discovery, CI.
2. **Phase 1 — CPU governor:** implement platform-aware governor controls.
3. **Phase 2 — egui shell:** three-pane UI, Tokyo Night theme, skills panel.
4. **Phase 3 — Providers and skill index:** provider connections and indexed skills.
5. **Phase 4 — OpenCode:** attach to an existing OpenCode instance, then add managed mode.
6. **Phase 5 — Slop Law:** prompt, lint, and sampling features. Sampling is only available for backends exposing generation logits (for example llama.cpp or koboldcpp).
7. **Phase 6 — Telegram bot:** Telegram interface integration.
8. **Phase 7 — Packaging:** AppImage with zsync, macOS DMG, and Windows installer. Planned releases are unsigned.
9. **Phase 8 — Polish:** accessibility, reliability, documentation, and release readiness.
